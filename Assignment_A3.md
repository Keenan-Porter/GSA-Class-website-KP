When I started out developing this project I wanted to make something dynamic. I thought it would be interesting to have the page being doing something on top of all the controls the user had.
I first implemented the basic setup from the tutorial and then changed the slider around to see what odd effects I could get with the colors. I found dividing the resolution by the slider first to be interesting so I chose that. I think having a simple control on a color slider creates some interesting effects. I then implemented the camera. I didn't want to just add all the camera values to the output like normal, so I random subtracted the values off. I think it makes a fun pseudo-inverted filter. I also added in mouse controls at can also affect the color on the x and y axis. At this point I wanted to keep experimenting with some basic color changing effects.

I moved onto the noise, I originally wanted to add a static effect. But, I found implementing a simplex noise added a geometric quality to the image that I thought added to the project. It seemed to take on a kaleidoscope quality that I found fun. I then leaned into that effect by adding a button to invert the colors on the noise which makes a fun duality like the edges on the effect. I then also added a slider to make the noise be more or less toggleable. I think overall I just made a fun little website that kinda reminds me of when I stare at the sun for too long.

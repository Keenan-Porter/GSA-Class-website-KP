For this project I created the most basic version of the simulated diffusion as I was restricted on time. I think the controls I added however were interesting. I gave the ability to control all the variables in the diffusion function excluding the seeding. I think this allows the user to watch already discovered patterns emerge, I additionally added was the ability to control the weighting of the surrounding in the Laplassian functions. Each direction responding to its own slider to possibly change what direction the chemicals react in or fade in. I think its a subtle addition that may lead to odd patterns emerging from non uniform weights.
